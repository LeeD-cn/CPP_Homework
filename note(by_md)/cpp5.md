# 第五节课笔记

## 日期3.24

### 4 运算符重载

- 操作符能否重载为友元或成员是有限制的；
  
#### 4.1 二目操作符的成员函数

- 最快：传引用，常函数；（一般不会修改）
  
#### 4.2 二目操作符的友元函数

- 最快：传两次（常）引用；**但是不能函数加const（只有成员函数能加const）**
  
#### 4.3 单目操作符的成员函数

- 前置void operator U()，后置void operator U(int)；
  
#### 4.4 单目操作符的友元函数

- 前置(==&==)，后置(==&==, int);必须传引用，否则无法修改成员值；
  
#### 4.5 特殊操作符的重载（先介绍“=”）（用于解决默认"="表示浅复制的问题）

- 返回*this（类型为引用,不是的话原则上可以）（为了能够连续赋值且效率高）！
- 加入检查自赋值机制（有时必须）——if(&obj2 != this)；
- ==**"=""+="等赋值操作符必须是成员函数，友元会报错**==；
  （*这是因为赋值要求左操作数必须是左值，非const成员函数的对象一定是左值，**说白了就是编译器懒得检查***）
  ++、--编译器不会管，但是做成员更合理；
- 含有字符串等指针可能为零的默认参数为""而不是NULL，防止NULL指向报错；

#### 4.6 <<、>>重载

- ==只能是友元，不能是成员==（如果是成员函数，左操作数为所在的类，但i/ostream类定义不能改）；
- 第一个形参是I/O的引用，第二个是待操作类，返回也是i/ostream对象的引用（为下次能仍然输出到cout上，而不是其副本）；
  
#### 4.7 类型操作符的重载

- （1）（类的）转换构造函数（其实就是类构造函数,能够在类型对不齐时自动调用）
- （2）（类之外类型-）类型转换函数:（优先级很高<出bug>，慎用）
  
```cpp
operator int()
{
    return 转换结果;
}
```

没有返回类型（因为一定会返回转换后的类型），没有参数(就是所在的类)；

- 每个类转换需求不同，所以类型转换函数只能定义为类的成员函数；

### 其他

- 空指针不能解引用；
- ".\*\"是归属于类的成员指针：在类外用类作用域定义，使用时obj.*p，指向同类对象obj的某个成员；
- 友元函数可以在类内声明，直接内联；
- explicit 限定词加在类型转换函数前，表示不能隐式转换，都得显示转化；
- 依靠另一个对象修改当前对象时要考虑自己做参数的情况，不能提前释放；
