# hw11_experience

## 第一题

- catch处理完错误之后，会接着执行这个try-catch后的程序；
- 能预判的错误在使用前检查，不能预判的错误在操作后检测或通过异常处理；前一种叫防御式编程，后一种叫异常驱动；
- 所以应该先检查 → 再访问，否则可能会没来得及处理异常就被系统杀掉了；非法行为会直接杀掉，而请求失败这种可以有自行处理的空间；
- 输入过大也会出错的，别忘了；

## 第二题

- 容器会自动delete，不需要手动delete；
- 对齐粘性，setw非粘性；
- string s的读取:cin >> s或getline(cin, s)分别读取一个词或整行，注意cin后衔接getline时要插入cin.ignore()吃掉换行符；
- qsort的升序是a-b,sort的升序是a < b;
