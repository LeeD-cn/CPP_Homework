# hw4_experience

## 第一题

- 初始化列表只能在构造（初始化）时使用，后续赋值不能用；
- const 是类型的一部分，声明和定义必须要一致；
- 函数返回时的内存构造：栈上构造一个临时变量（赋初始值为返回值），之后函数的局部变量销毁，之后用这个临时变量进行赋值操作，最后这个临时变量被销毁；
- 函数调用传参前，所有参数表达式都会先算完;
  (++a 这个表达式的值是加之后的值
  a++ 这个表达式的值是加之前的值)
